# Импорт макета Figma по ссылке без локального запуска и ручного токена

## Статус

В редакторе уже есть поле «Импорт по ссылке», выбор фреймов, предпросмотр и добавление редактируемых секций. В репозитории также подготовлен сервер Figma OAuth и GitHub Actions для его облачного развёртывания.

**До одноразовой настройки владельцем облачного OAuth-сервиса импорт по ссылке недоступен.** Это не ошибка ссылки: GitHub Pages выполняет только статический фронтенд и не может хранить секреты Figma. JSON-импорт остаётся доступным.

## Как это работает для редактора после настройки

1. Открыть https://kssafonova.github.io/merchtest/ и нажать «Из Figma».
2. Вставить обычную ссылку Figma Design / Prototype на файл или Frame.
3. Если ранее не подключались, нажать «Импортировать» и пройти вход **через Figma**. Личный API-токен вводить не нужно; при наличии действующего сеанса вход повторять не надо.
4. После возвращения на сайт редактор автоматически запросит слои макета и покажет список фреймов. Выбрать нужные.
5. Нажать «Импортировать» — секции появятся на холсте как DOM-слои и доступный для редактирования текст.

Работают **только файлы, к которым вошедший пользователь имеет доступ**. «Любую чужую приватную ссылку» Figma API не разрешает читать даже после авторизации пользователя. Не поддерживаемые как полноценная вёрстка типы (например FigJam/Slides, сложная векторная маска, интерактивные прототипы) требуют отдельного адаптера.

## Одноразовая настройка владельцем проекта — полностью из браузера

1. На https://www.figma.com/developers/apps создать Figma OAuth app (при необходимости оформить команду). Сохранить Client ID и Client Secret в надёжном хранилище, не публиковать их. Выбрать OAuth scope **file_content:read**. Для предоставления доступа всем пользователям потребуется публичное приложение и одобрение Figma; для внутреннего использования можно выбрать private с ограничением пользователей команды.
2. В Cloudflare создать учётную запись Workers и API Token с правами развёртывания Worker; сохранить Cloudflare Account ID.
3. Открыть настройки GitHub репозитория **Settings → Secrets and variables → Actions → Secrets**. Добавить:

   | Имя GitHub Secret | Значение |
   | --- | --- |
   | `CLOUDFLARE_API_TOKEN` | Токен деплоя Cloudflare |
   | `CLOUDFLARE_ACCOUNT_ID` | ID Cloudflare account |
   | `FIGMA_CLIENT_ID` | ID созданного OAuth-приложения Figma |
   | `FIGMA_CLIENT_SECRET` | Секрет OAuth-приложения |
   | `FIGMA_SESSION_SECRET` | Случайный длинный криптографический секрет (не менее 32 байт) |

4. Открыть **Actions → Deploy Figma OAuth Bridge → Run workflow**. Это выполняет деплой на Cloudflare без команд на компьютере. После деплоя URL сервиса будет похож на `https://merchtest-figma-oauth.<account>.workers.dev`.
5. В настройках OAuth-приложения Figma указать точный Redirect URL: `https://merchtest-figma-oauth.<account>.workers.dev/auth/callback`, выбрать нужные scopes и опубликовать приложение.
6. В GitHub **Settings → Secrets and variables → Actions → Variables** добавить переменную **FIGMA_BRIDGE_URL** со значением URL облачного Worker (без `/auth/callback`).
7. В GitHub **Actions → Deploy React prototype to GitHub Pages → Run workflow** пересобрать сайт. UI подключится к Worker.
8. Проверить `https://merchtest-figma-oauth.<account>.workers.dev/health`: `ready:true` означает, что Worker видит нужные переменные. Затем испытать ссылку на доступный Figma Frame.

Не нужно передавать секреты в чат. GitHub Secrets и Worker Secrets должны оставаться серверными.

## Устройство и безопасность

- `figma-hosted/worker.mjs` — Cloudflare Worker: OAuth authorization code flow, проверка подписанного state, обмен кода, зашифрованная краткосрочная сессия и Figma REST API. Данные макета доступны только после OAuth.
- `figma-hosted/wrangler.toml` — конфигурация Worker.
- `.github/workflows/figma-hosted.yml` — деплой Worker из интерфейса GitHub Actions.
- `src/figma-hosted-client.mjs` — клиентский API-адаптер. В браузере хранится только временный зашифрованный сеанс, **не** Figma access token.
- `src/FigmaBridge.jsx` — поле URL, авторизация, предпросмотр, JSON fallback.
- `src/figma-bridge.mjs` — преобразование слоёв Figma в редактируемые секции.

Worker ограничивает запросы разрешённым браузерным Origin, валидирует домен Figma и не допускает произвольные API URL. Сессия действует не дольше одного часа, сохраняется только в текущей браузерной сессии. Секреты не попадают в HTML или GitHub Pages.

### Известные ограничения

Текущий импорт переносит слои (текст, фоны, изображения, размеры, Auto Layout), но не создаёт произвольную бизнес-логику автоматически и не гарантирует pixel-perfect адаптивность сложных абсолютных фреймов. Изображения ограничены по количеству и размеру ради безопасной передачи. Импортированные изменения сохраняются в браузере, но пока не синхронизируются между устройствами.
